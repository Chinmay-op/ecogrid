# OmniView IQ

Landing page for OmniView IQ — the triple-impact engine for industrial energy, compliance, and carbon.

Content is sourced from `omniview-iq-website-content.md` and structured in `src/content/site.ts`.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Add your video

Save your file as `public/hero-video.mp4`. Until then, an industrial-themed placeholder shows on the right half of the hero.

## Stack

- Next.js 16 (App Router)
- React 19
- GSAP + ScrollTrigger
- Tailwind CSS 4
